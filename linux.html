Wildcards & globbing

Shell patterns are useful for working with groups of files without naming each one individually.

* Any number of characters
? Exactly one character
[abc] One character from the set
[0-9] One character from a range 
*.html

2026-*.html

image-??.jpg

file[0-9].txt

Permissions

Linux permissions control who can read, write and execute a file. 

ls -l file.txt

chmod 644 file.txt

chmod +x script.sh

chown user:group file.txt

Permission numbers 

4 = read
2 = write
1 = execute

7 = read + write + execute
6 = read + write
5 = read + execute
4 = read only
